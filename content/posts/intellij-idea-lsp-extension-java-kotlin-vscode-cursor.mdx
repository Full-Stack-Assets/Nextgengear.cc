Developers using lightweight editors have long missed the deep code insight that IntelliJ IDEA provides. JetBrains just announced a preview LSP extension that brings Java and Kotlin intelligence to VS Code, Cursor, and other LSP‑compatible tools. The move aligns IDE power with the rise of agentic development, where AI agents handle much of the coding work. By exposing smart completion, navigation, and analysis through LSP, the extension promises to boost productivity without the overhead of a full IDE. Early trials suggest noticeable gains for terminal‑based AI workflows.

<Callout type="takeaway">IntelliJ IDEA’s Java & Kotlin LSP extension delivers full‑IDE intelligence to lightweight editors.</Callout>

## What happened
JetBrains released a preview “Java & Kotlin by IntelliJ IDEA” extension, now listed in the Visual Studio Marketplace and the Open VSX registry. The extension implements IntelliJ’s language server for Java and Kotlin, exposing smart code completion, navigation, and on‑the‑fly analysis to any LSP‑compatible editor.

The server automatically imports Maven, Gradle, or Bazel projects and supports mixed‑language codebases, delivering fast performance even on large monorepos. JetBrains also shared early internal trials where AI agents using the LSP server completed tasks with lower token consumption and higher determinism.

## Why it matters
Bringing IntelliJ‑grade intelligence to lightweight editors lowers the barrier for developers and AI agents to access advanced language features without launching a heavyweight IDE. This can reduce context‑switching, speed up agentic workflows, and make Java/Kotlin development more accessible in cloud‑based or terminal‑centric environments.

## How to think about it
Start by installing the extension in a non‑critical project to gauge performance and feature coverage. Compare its code‑completion and navigation against the full IDE to decide if it meets your daily needs. If you rely heavily on AI‑driven coding, test the LSP server’s impact on token consumption in your agentic pipelines. Keep an eye on JetBrains’ upcoming updates, as feature parity will grow over time.
