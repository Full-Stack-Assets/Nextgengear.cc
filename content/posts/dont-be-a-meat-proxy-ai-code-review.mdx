Developers are increasingly tossing AI‑generated snippets into pull‑request discussions without reading them first. The practice, dubbed “meat proxy” by a recent blog post, treats the AI as a middleman that simply relays output. While it can speed up drafting, it forces reviewers to decode verbose, jargon‑laden text and adds hidden risk. Understanding the original intent and validating the code remains essential. Ignoring this step erodes the value that human review brings to software quality.

<Callout type="takeaway">Relying on AI as a mere messenger strips away the critical validation that makes code reviews valuable.</Callout>

## What happened
The author repeatedly receives Slack questions, PR feedback, and WhatsApp arguments that end with a terse "Please don't do this." They explain that many teammates copy‑paste a ticket description into Claude, let the model generate code, and then forward the AI's output without ever reading it. The resulting AI text is often verbose, filled with plausible nonsense, and dense with jargon, forcing reviewers to look up almost every word.

In code reviews, this pattern becomes a shortcut: the ticket description is fed to Claude Code, the generated implementation is posted, and any reviewer comments are fed back into Claude for iteration. The reviewers end up approving code they never examined, while the original author becomes a "meat proxy"—a conduit for AI output rather than a thoughtful contributor.

## Why it matters
When AI output is treated as a black box, the essential human step of understanding and validating code disappears. Bugs slip through because no one has verified the logic, and knowledge transfer stalls as team members skip the learning that comes from reading and critiquing code. Over time, reliance on AI as a proxy can erode code quality, increase technical debt, and create a false sense of productivity.

## How to think about it
Treat AI as a collaborative assistant, not a substitute for your own reasoning. Start by prompting the model for ideas, then read the generated code line‑by‑line, verify its correctness, and rewrite it in your own words before sharing. Use the AI‑produced snippet as a reference, not as the final answer. Document any assumptions you uncover during validation, and encourage reviewers to do the same. By keeping the human loop tight, you capture the speed benefits of AI while preserving code quality and shared understanding.

<Callout type="warning">Do not merge code that you have not personally inspected; doing so can introduce subtle bugs and security vulnerabilities.</Callout>
