# Analytics and monetization activation

Set `NEXT_PUBLIC_GA_MEASUREMENT_ID` to the `nextgengear.cc` stream in the portfolio GA4 property and `NEXT_PUBLIC_PORTFOLIO_SITE_ID=nextgengear`. The script is omitted when the ID is absent.

The shared contract records article scroll depth, outbound/internal clicks, affiliate clicks, and tagged CTAs. Activate the Amazon program only by setting a real approved tag; never substitute a placeholder. Register the event parameters as GA4 custom dimensions, verify Search Console, link AdSense, and install a Google-certified CMP before applicable personalized or non-personalized ad serving. AdSense stays disabled until `NEXT_PUBLIC_GOOGLE_CERTIFIED_CMP_ACTIVE=true`; set that only after provider verification.

The same fail-closed relevance gate is applied both before new topics are scored and when persisted posts are exposed to the static renderer. Off-niche source files remain in the repository for review and recovery, but they are omitted from home, taxonomy, feed, sitemap, and generated post routes.
